# Codex Local Mode

`graphify-init --local` configures Graphify for one developer's Codex workspace. The mode is Codex-only; selecting another platform exits before repository files change. `--no-base-agents` is valid only with `--local`.

The mode runs Graphify's Codex project installer in a temporary directory and copies only its skill into the repository. Graphify's installer also writes `AGENTS.md` and `.codex/hooks.json`, so running it directly in the repository would violate local mode. A changed local `SKILL.md` is backed up before replacement. The mode writes Graphify instructions to ignored `AGENTS.override.md`. By default, those instructions explicitly tell Codex to read an existing `AGENTS.md`, because Codex loads only the override from a directory. `--no-base-agents` omits that instruction for repositories with obsolete base guidance. A pre-existing local Graphify override keeps its instructions; only the optional base reference is managed.

`.gitignore` ignores `AGENTS.override.md`, `.codex/hooks.json`, `.codex/skills/graphify/`, `.graphifyignore`, and `graphify-out/`. Already tracked files cannot be ignored, so local mode fails before writing and gives a `git rm --cached` command for the user to review. Existing exact rules are reused without duplication. `.graphifyignore` keeps excluding installed Graphify skill sources. Managed blocks are validated before any repository file is written, preserve unrelated content, and are rewritten only if bytes change.

An existing `graphify-out/graph.json` skips extraction and clustering on every mode unless a `.graphify_init_progress` marker shows the initializer stopped before completing them. The marker records which step needs retry and is removed after clustering succeeds. Users refresh a completed graph with `graphify update .`. Local mode skips new Git hook installation, so it does not add a Graphify merge-driver entry to `.gitattributes`; any already installed hooks remain in place. Default mode retains project integration and hook installation.
